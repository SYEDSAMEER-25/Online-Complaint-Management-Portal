# ResolveNow — Online Complaint Management Portal

A responsive frontend college-project demo built with HTML, CSS and vanilla JavaScript.

## Features
- Complaint submission form with basic browser validation
- Automatically generated complaint IDs
- Complaint tracking by ID
- Dashboard with status filters and demo status changes
- Browser local storage
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Publish on GitHub Pages
1. Create a GitHub repository named `online-complaint-portal`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/online-complaint-portal/`.

## Important limitation
This is a frontend demonstration. Complaint data is saved only in the current browser using localStorage. It is not sent to a server, shared with other visitors, or delivered to an authority. Do not enter real personal or sensitive information. A production system needs a secure backend, database, authentication, and appropriate privacy/security controls.
